    \begin{flushleft}

        \textbf{Nombre:} Estimación incorrecta de los tiempos en el plan de tareas.\linebreak
        \textbf{Descripción:} El riesgo puede ocurrir como una subestimación o una sobreestimación de los tiempos del plan de tareas.\linebreak
        \textbf{Indicador:} Error relativo porcentual entre el progreso estimado de cada tarea para cada día y el real.\linebreak
        \textbf{Probabilidad de ocurrencia:} 3 \linebreak
        \textbf{Impacto:} Medio, el proyecto se puede retrasar o adelantar\linebreak
        \textbf{Estrategia a adoptar:} Si el indicador es mayor al 10\%, se trabajarán horas extras para recuperar el progreso perdido y respetar el calendario de tareas. \linebreak
        Si el indicador es mayor al 35\% se deberán replanificar las tareas que se encuentren en etapa de ejecución y las siguientes a la misma.\linebreak
        Se busca mitigar el impacto sobre las fechas de entrega para que la diferencia entre el momento planificado y el real sea mínima.\linebreak

        \textbf{Nombre:} Ausencia de los RRHH    \linebreak
        \textbf{Descripción:} El riesgo ocurre ante la ausencia de parte o totalidad del personal del proyecto.    \linebreak
        \textbf{Probabilidad de ocurrencia:} 2. \linebreak
        \textbf{Indicador:} Cantidad de personas disponibles, haciendo énfasis en el desarrollador.    \linebreak
        \textbf{Impacto:} Medio. El proyecto puede detenerse hasta el regreso del desarrollador, pero puede continuar ante la ausencia del director o los ayudantes. \linebreak
        \textbf{Estrategia:} Ante la ausencia del desarrollador, se aceptará activamente, y se replanificarán las tareas. Ante la ausencia de director y/o ayudantes se aceptará pasivamente.    \linebreak
    \end{flushleft}
